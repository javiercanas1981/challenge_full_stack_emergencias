#### Estilos en Taildwind

---

Para dar estilos se usó Tailwind como framework.

## Breackpoints desarrollados:

• 360px, 768px, 1366px y 1920px.

#### Gestión de Contactos

- **CRUD Completo**: Creación, edición, visualización y eliminación de contactos.
- **Multi-entidad**: Posibilidad de añadir múltiples números de teléfono (con tipo) y múltiples direcciones a un solo contacto.
- **Búsqueda Avanzada**: Filtros por nombre, apellido, email y número de teléfono.

## Redux desarrolladas:

- **React** con **TypeScript**.
- **Redux** para el manejo del estado global.
- **Tailwind CSS** para los estilos y diseño responsive.
- **Axios** para el consumo de la API REST.
- **React Router** para la navegación.
